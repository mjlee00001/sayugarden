사유의 정원 SNS 퍼블리셔 개인정보처리방침

시행일: 2026년 10월 11일 · 개정: 2026년 10월 14일 (Meta 서비스 · 링크 허브 방문 통계 추가)

「사유의 정원 SNS 퍼블리셔」(이하 "본 앱")는 블로그 「사유의 정원」 운영자가 자신의 블로그 글로 만든 짧은 영상을 운영자 본인의 SNS 계정(YouTube, Instagram, Threads, Facebook 페이지)에 게시하기 위해 직접 만들어 사용하는 개인용 도구입니다. 본 앱은 운영자 본인 외의 이용자를 대상으로 하지 않으며, 이 페이지가 있는 링크 허브는 운영자의 SNS 프로필에서 블로그 글로 안내하는 소개 페이지입니다.

1. 본 앱이 이용하는 정보 (운영자 본인 계정)

  • Google(YouTube): 운영자 채널에 영상을 올리고 통계를 확인하기 위해 Google OAuth로 받은 액세스 토큰 · 갱신 토큰, 채널 이름, 운영자 채널 영상의 조회 · 좋아요 · 댓글 수 등 통계
  • Meta(Instagram · Threads · Facebook 페이지): 운영자 계정에 릴스 · 게시물을 올리고 통계를 확인하기 위해 받은 액세스 토큰, 계정 · 페이지 이름과 ID, 운영자 게시물의 조회 · 좋아요 · 댓글 · 공유 수와 팔로워 수
  • 본 앱은 다른 사람의 계정 정보, 댓글 내용, 메시지는 수집하지 않습니다.

2. 이용 목적

  • 운영자 본인 계정에 영상 · 제목 · 설명 · 썸네일을 게시
  • 게시 결과(게시물 ID · 주소)를 기록해 중복 게시를 방지
  • 운영자 게시물의 반응을 모아 운영자 본인이 보는 보고서를 작성

3. 링크 허브 방문 통계

  • 이 링크 허브는 방문 수와 글 클릭 수를 세기 위해 GoatCounter(https://www.goatcounter.com)를 사용합니다.
  • 쿠키를 사용하지 않으며, 이름 · 이메일 등 개인을 알아볼 수 있는 정보를 수집하지 않습니다. 어느 SNS에서 들어왔는지, 어떤 글을 눌렀는지, 브라우저 종류 · 화면 크기 · 국가 같은 집계용 정보만 기록됩니다.
  • GoatCounter의 개인정보처리방침: https://www.goatcounter.com/help/privacy

4. 보관 및 보호

  • 인증 토큰은 운영자 PC의 Windows 자격 증명 관리자에만 저장되며, 외부 서버로 보내거나 따로 보관하지 않습니다.
  • 게시 기록과 통계는 운영자 PC에만 저장됩니다. 본 앱은 운영자 PC 안에서만 접속할 수 있도록 실행됩니다.

5. 제3자 제공

  • 본 앱은 정보를 제3자에게 제공하거나 판매하지 않습니다.
  • 게시와 통계 확인에는 각 플랫폼의 공식 API를 사용하며, 각 플랫폼의 개인정보처리방침이 적용됩니다: Google https://policies.google.com/privacy · Meta https://www.facebook.com/privacy/policy

6. Google API 서비스 사용자 데이터 정책 준수

  • 본 앱이 Google API로부터 받은 정보의 사용 및 다른 앱으로의 전송은 제한적 사용 요건을 포함한 Google API 서비스 사용자 데이터 정책(https://developers.google.com/terms/api-services-user-data-policy)을 준수합니다.
  • 본 앱은 YouTube API 서비스를 사용하며, YouTube 서비스 약관(https://www.youtube.com/t/terms)이 적용됩니다.

7. 권한 철회 및 데이터 삭제

  • Google: Google 계정 › 보안 › 타사 액세스(https://myaccount.google.com/permissions)에서 언제든지 본 앱의 접근 권한을 철회할 수 있습니다.
  • Meta: Facebook 설정 › 앱 및 웹사이트(https://www.facebook.com/settings?tab=applications), Instagram 설정 › 앱 및 웹사이트에서 본 앱을 삭제할 수 있습니다.
  • 본 앱 화면에서 "연결 해제"를 누르면 저장된 토큰이 즉시 삭제됩니다.
  • 데이터 삭제 요청: 아래 이메일로 요청하시면 본 앱이 보관한 해당 정보를 30일 이내에 삭제하고 결과를 알려 드립니다. 본 앱은 운영자 외 이용자의 정보를 보관하지 않으므로, 링크 허브 방문자에 대해 삭제할 개인 정보는 없습니다.
