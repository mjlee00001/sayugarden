사유의 정원 SNS 퍼블리셔 개인정보처리방침

시행일: 2026년 10월 11일

「사유의 정원 SNS 퍼블리셔」(이하 "본 앱")는 블로그 「사유의 정원」 운영자가 자신의 블로그 글로 만든 짧은 영상을 운영자 본인의 YouTube 채널 등 SNS 계정에 게시하기 위해 직접 만들어 사용하는 개인용 도구입니다. 본 앱은 운영자 본인 외의 이용자를 대상으로 하지 않습니다.

1. 이용하는 정보

  • Google 계정 인증 정보: 운영자 본인의 YouTube 채널에 영상을 업로드하기 위해 Google OAuth로 발급받은 액세스 토큰과 갱신 토큰
  • YouTube 채널 기본 정보: 연결 상태 확인을 위한 채널 이름
  • 이메일 주소: Google 로그인 계정 확인 용도

2. 이용 목적

  • 운영자 본인의 YouTube 채널에 영상, 제목, 설명, 썸네일을 업로드
  • 게시 결과(영상 ID, 주소)를 기록하여 중복 게시를 방지

3. 보관 및 보호

  • 인증 토큰은 운영자 PC의 Windows 자격 증명 관리자에만 저장되며, 외부 서버로 전송하거나 별도로 보관하지 않습니다.
  • 본 앱은 운영자 PC 안에서만 접속할 수 있도록 실행됩니다.

4. 제3자 제공

  • 본 앱은 수집한 정보를 제3자에게 제공하거나 판매하지 않습니다.
  • 영상 업로드 시 Google(YouTube)의 API를 사용하며, 이 과정에는 Google의 개인정보처리방침(https://policies.google.com/privacy)이 적용됩니다.

5. Google API 서비스 사용자 데이터 정책 준수

  • 본 앱이 Google API로부터 받은 정보의 사용 및 다른 앱으로의 전송은 제한적 사용 요건을 포함한 Google API 서비스 사용자 데이터 정책(https://developers.google.com/terms/api-services-user-data-policy)을 준수합니다.
  • 본 앱은 YouTube API 서비스를 사용하며, YouTube 서비스 약관(https://www.youtube.com/t/terms)이 적용됩니다.

6. 권한 철회 및 삭제

  • Google 계정 › 보안 › 타사 액세스(https://myaccount.google.com/permissions)에서 언제든지 본 앱의 접근 권한을 철회할 수 있습니다.
  • 본 앱 화면에서 "연결 해제"를 누르면 저장된 토큰이 즉시 삭제됩니다.
